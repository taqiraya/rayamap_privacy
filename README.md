# Rayamap Privacy

Public privacy and permissions page for the Rayamap browser extension.

## Enable GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, folder **/ (root)**, and save.
4. Wait for the Pages deployment to finish.

Expected public URL after deployment:
https://taqiraya.github.io/rayamap_privacy/

The same policy is also available at `/rayamap_privacy/privacy.html`.
Use the deployed HTTPS URL in the extension store's Privacy Policy URL field.

`index.html` and `privacy.html` contain the same English policy. `theme.css` is a local stylesheet; this site has no JavaScript, API keys, analytics, or tracking code.
